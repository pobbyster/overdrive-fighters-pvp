# Overdrive Fighters PvP — 0.13.0

Distribuição web preparada do jogo. Instale dependências com npm ci --omit=dev --ignore-scripts e inicie com npm start. Node >=22. PORT fornecido pela hospedagem; saúde em /pvp-health; WebSocket em /pvp.

As fontes de desenvolvimento e dados pessoais não fazem parte desta distribuição. Configure OFS_PVP_STATE_FILE fora da pasta pública e preserve o arquivo de salas conforme a infraestrutura utilizada. Não envie arquivos .env ou credenciais ao repositório.
